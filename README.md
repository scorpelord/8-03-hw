### Задание 3

1* VMware vSphere
- Отличная совместимость с Windows
- Поддерживает программные балансировщики нагрузки и репликацию данных
- Предлагает возможности для автоматизации резервного копирования

2* Proxmox VE
- Бесплатное решение с открытым исходным кодом
- Поддерживает KVM и LXC, обеспечивая высокую производительность
- Работает как с Linux, так и с Windows виртуальными машинами

3* Microsoft Hyper-V Server
- Максимальная совместимость
- Hyper-V Server бесплатный
- Оптимизировано для работы с Windows-системами

4* VirtualBox
- Поддерживает работу с различными дистрибутивами Linux
- VirtualBox бесплатный
- Легкая настройка
