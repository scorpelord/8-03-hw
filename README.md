### Задание 2

*SYN-сканирование:

-Использует полуоткрытые соединения. Отправляет пакеты с флагом SYN

-Сервер отвечает SYN-ACK, если порт открыт, или RST, если закрыт

*Ответ сервера:

Сервер отвечает с SYN-ACK для открытых портов или RST для закрытых

*FIN-сканирование:

-Отправляет пакеты с флагом FIN

-Открытые порты не отвечают, закрытые отправляют RST

Ответ сервера:

Отсутствие ответа указывает на открытый порт; ответ RST указывает на закрытый порт

*Xmas-сканирование:

-Отправляет пакеты с флагами FIN, PSH и URG

-Открытые порты не отвечают, закрытые отправляют RST

Ответ сервера:

Отсутствие ответа указывает на открытый порт; ответ RST указывает на закрытый порт

*UDP-сканирование:

-Отправляет пустые UDP-пакеты

-Если порт открыт, обычно нет ответа, если закрыт, сервер отвечает ICMP пакетами "порт недоступен"

Ответ сервера:

Отсутствие ответа может указывать на открытый порт, ICMP "порт недоступен" указывает на закрытый
