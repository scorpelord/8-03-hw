# Домашнее задание к занятию "Базы данных, их типы" - Молоствов Андрей



Кейс
Крупная строительная компания, которая также занимается проектированием и девелопментом, решила создать правильную архитектуру для работы с данными. Ниже представлены задачи, которые необходимо решить для каждой предметной области.

Какие типы СУБД, на ваш взгляд, лучше всего подойдут для решения этих задач и почему?
```
1.1 Для бюджетирования проектов и финансовых аналитических отчётов лучше всего подойдёт реляционная СУБД, такая как PostgreSQL или Oracle. Они обеспечивают целостность данных и чёткую структуру благодаря поддержке транзакций и строгой схемы данных.
1.1* Для ускорения хеширования можно использовать API, предоставляемые такими библиотеками, как PyCrypto или bcrypt, которые оптимизированы для производительности.
1.2  Для лендингов и CRM подойдут NoSQL СУБД, такие как MongoDB или Couchbase. Они обеспечивают гибкость и высокую скорость работы с данными.
1.2* Можно использовать одну СУБД, например, MongoDB, которая способна справиться с гибкими данными лендингов и CRM благодаря своей документно-ориентированной модели.
1.3 Для базы данных по корпоративным нормам и правилам подойдёт реляционная СУБД, например, MySQL, из-за её простой и понятной структуры.
1.3* Можно использовать ту же реляционную СУБД, что и для бюджетирования проектов (например, PostgreSQL), создав отдельную схему или базу данных для разделения данных.
1.4 Для логистики и маршрутов доставки лучше всего подойдёт графовая СУБД, такая как Neo4j, которая быстро работает со связями и позволяет эффективно управлять маршрутами.
1.4* Можно подключить отдел закупок к той же графовой СУБД, но для лучшей производительности и изоляции данных может потребоваться отдельная инстанция СУБД.
1.5* Решить все задачи одной СУБД сложно, так как они требуют разных моделей данных и оптимизаций. Однако, если необходимо использовать одну СУБД, можно рассмотреть использование PostgreSQL благодаря её расширяемости и поддержке различных типов данных с помощью дополнений и расширений. Но это будет компромиссное решение.
```
